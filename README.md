### Penjelasan Folder

#### `lib/`

Folder utama tempat kode Dart aplikasi ditulis.

File utama:

```text
lib/
└── main.dart
```

`main.dart` merupakan entry point utama aplikasi Flutter.

#### `android/`

Berisi konfigurasi dan file yang diperlukan untuk menjalankan aplikasi pada platform Android.

#### `ios/`

Berisi konfigurasi untuk menjalankan aplikasi pada platform iOS.

#### `web/`

Berisi konfigurasi yang diperlukan untuk menjalankan aplikasi Flutter pada browser.

#### `windows/`

Berisi konfigurasi untuk menjalankan aplikasi Flutter pada Windows.

#### `linux/`

Berisi konfigurasi untuk menjalankan aplikasi Flutter pada Linux.

#### `macos/`

Berisi konfigurasi untuk menjalankan aplikasi Flutter pada macOS.

#### `test/`

Digunakan untuk menyimpan kode pengujian aplikasi.

#### `.dart_tool/`

Berisi file yang dibuat dan digunakan oleh Dart/Flutter.

Folder ini biasanya tidak perlu diedit secara manual.

#### `.idea/`

Berisi konfigurasi project yang digunakan oleh IDE seperti Android Studio atau IntelliJ IDEA.

#### `build/`

Berisi file hasil proses build Flutter.

Folder ini dibuat secara otomatis oleh Flutter.

## ▶️ Getting Started

Pastikan Flutter sudah terinstall pada komputer.

Cek instalasi Flutter:

```bash
flutter doctor
```

Clone repository:

```bash
git clone https://github.com/FaletehanAlF/Learning-Flutter.git
```

Masuk ke folder project:

```bash
cd Learning-Flutter
```

Install dependencies:

```bash
flutter pub get
```

Jalankan project:

```bash
flutter run
```

Untuk melihat device yang tersedia:

```bash
flutter devices
```
